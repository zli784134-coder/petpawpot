# 发给工厂的话术(可直接复制)

> 拆成两条发。第一条最重要且最可能已有答案,单独发回复率更高。
> 第二条是下次测试的补充要求,可以晚一点发。

---

## 第一条:先要已有的称重数据

```
老师好,温升报告收到了,数据很完整,谢谢。

有个事想确认一下:8月15号那次测试(肉松1H)的照片里,看到14:17
用电子秤称了食材,显示501.4g。想请教三个问题:

1、这个501.4g是净重(去过皮的)还是连红盆一起的毛重?
2、程序跑完之后有没有也称一次熟重?如果有,是多少?
3、那次一共放了哪几样、各多少克?(照片里看着有鸡腿肉,
   还有一块深色的,像是内脏)

我们这边需要"生重→熟重"的得率数据来做配方换算。如果你们
之前的测试已经有称重记录,直接把记录发我们就行,不用重新做。
```

## 第二条:下次测试请补一根食物中心热电偶

```
另外有个补充需求,想在下次测试时加一根线。

现在报告里的7个测点都在机器上。桶内壁那根按你们说的是贴在
比较靠上的位置(避开搅拌桨),所以它量到的其实是桶壁温度,
不是食物温度。

想请在下次测试时,在桶内食物堆的中心再插一根热电偶:
- 探针尖端离桶壁、桶底都保持2cm以上
- 采样率跟现在一样1秒就行
- 曲线原始数据一并给我们(不要只给峰值,我们需要看保持时间)

这根线和称重可以在同一次测试里一起做,不用分两次。

优先想测的食材:羔羊肉、鳕鱼、藜麦、大麦这四样(我们目前
用的是估算值),再加鸡腿肉和白米饭(用量最大)。
程序覆盖快煮和精煮两档就够。
```

## 第三条(可选,晚点再问):程序时长核对

```
还有个小问题想核对一下。我们看实测的程序时长是:
湿粮约50分钟、快煮约32分钟、精煮约73分钟、肉松整60分钟、
生骨肉约14分钟(全程没加热)、清洗约26分钟。

想确认两件事:
1、这些是程序跑完的自然时长,还是测试中手动停止的?
   (精煮那张图看着73分钟还在正常控温,像是手动停的)
2、生骨肉档设计上就是不加热的对吗?

因为我们说明书上标的时间和这个对不上,想搞清楚是说明书的
问题还是测试没跑完。
```
